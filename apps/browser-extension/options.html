Reading and translation

External/passive mode disables Ogleans scheduling and never reads another extension's storage, credentials or runtime messages. Built-in translation sends page text only after you explicitly invoke it.

Providers

API keys and custom headers stay in the trusted extension worker. Exports redact them.

Gestures and keyboard alternatives
SequenceAction
KeyboardAction

Use comma-separated directions such as up,right. Defaults use Alt + drag; ordinary clicks and right-click context menus are left alone.

Collections

Bookmark access is optional and requested only when you enable it. Existing bookmarks are never overwritten or deleted. Ogleans remains the canonical store for notes, tags, anchors and translations.

Advanced

Change global browser shortcuts at chrome://extensions/shortcuts. The collection data is not deleted by Reset settings.
