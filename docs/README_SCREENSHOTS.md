# README screenshots

The committed screenshots are produced by the real Chromium extension E2E suite.

- `extension-settings-v0.2.0-alpha.1.png`: Ogleans settings with translation modes, provider policy controls, gesture mappings and collection settings.
- `collection-disabled.png`: floating collection surface while built-in translation is disabled.
- `collection-external.png`: collection surface in passive external mode.

They are generated by:

```sh
pnpm build
pnpm e2e
```

The E2E suite uses a fresh persistent Chromium test profile and a test-only localhost permission grant. The release manifest remains unchanged except for the optional bookmark permission model being asserted separately.

Screenshots show configuration and interaction surfaces, not provider-quality claims and not proof that another third-party extension was controlled.
